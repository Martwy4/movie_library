Movie Library

Web application built with Python and Flask that integrates with the TMDb API.

Features

✔ Search movies
✔ Browse popular movies
✔ View movie details
✔ Add movies to favourites
✔ Store user data in SQLite
✔ Responsive Bootstrap interface

Tech Stack

- Python
- Flask
- SQLite
- SQLAlchemy
- HTML
- CSS
- Bootstrap
- Requests
- Git

API

TMDb API

Installation

git clone ...
pip install -r requirements.txt
flask run
